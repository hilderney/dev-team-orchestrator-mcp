# Requirements — skills catalog enrichment (lab)

## Goal
Have the zteam roles propose what belongs in each Phase-9 skill file (role × phase × projectType), especially P0 webgame + crud.

## Functional
- Each role owns skills listed in skill-briefing.md for that role only.
- Proposals must respect TDD: red before green; [x] only on verify.
- Webgame skills must cover Flow & states / overlay exclusivity.
- CRUD/API skills must cover validation + alt paths without forcing arcade UX.

## Non-functional
- Keep each skill ≤1 page when later applied.
- No implementation of product code in this lab.

## Acceptance
- Analysis review lists ### skill-file.md sections for P0 skills with Must deliver + Anti-patterns.
- Gaps called out when a stub is too vague to become `pilot`.
