# Skill — SA todo plan (core)

**Role:** systemArchitect · **Phase:** todo-plan · **projectType:** core · **needsUiFlow:** — · **Status:** pilot  
**Source:** team analyze `skills-sa-review.md` (2026-09-26)

## Mission
Decompose requirements into a TDD-sequenced execution plan (testable chunks).

## Must deliver
- `.docs/todo.md` with `- [ ] slug: title`
- Dependency-ordered tasks (P0 → P1)
- Mapping of tasks to QA-red → SE-green → QA-verify
- Definition of Done for each milestone
- Risk notes for critical paths

## Anti-patterns
- Creating a Gantt chart instead of a checklist
- Planning implementation before QA-red can assert ACs
- Mega-slugs that cannot be verified
- Over-granularity (noise tasks)

## Artefacts
- `.docs/todo.md`
- Milestone / sequencing notes in plan section
