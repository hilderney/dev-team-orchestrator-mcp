## Mission
Define visual identity and chrome hierarchy for the game interface.

## Must deliver
- Cohesive palette (primary/secondary/accent/danger)
- Typography scale for HUD/menus
- Overlay/chrome hierarchy in design
- Layout grid: canvas vs UI overlays
- HUD visual hierarchy

## Anti-patterns
- Generic browser defaults for game chrome
- Inconsistent spacing across menus
- Contrast failures (accessibility)
