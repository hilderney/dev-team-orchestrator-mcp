## Mission
Translate requirements into per-slug specs (≥3 use cases) before UX/TA enrich.

## Must deliver
- Functionalities, actions/reactions
- ≥3 use-case examples (≥1 per scenario)
- Interface-level inputs/outputs
- Edge/alt-path handling
- Files to touch + acceptance (no “hook exists” DoD)

## Anti-patterns
- Writing code snippets in the spec
- Ambiguous language (“should be fast”, “user-friendly”)
- Specifying stack “how” (TA’s job) instead of product “what”
