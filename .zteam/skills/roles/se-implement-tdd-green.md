# Skill — SE implement (TDD green)

**Role:** softwareEngineer · **Phase:** tdd-green · **projectType:** webgame | webapp | crud | api

## Mission
Make QA-red tests pass. Implement product code only — do not own `[x]` on todos.

## Must deliver
- Code that turns red tests green (`tsc` + suite)
- Respect `technologies.md`, specs, and `## Flow & states` when present
- `===SELF_CHECK===`: functionalities, use cases, usability/emotions
- Screen-flow: overlays exclusive; do not invent parallel chrome

## Anti-patterns
- Marking todos `[x]` (QA-verify owns that)
- Deleting or weakening red tests to “pass”
- Writing the first tests for a Flow & states slug (that is QA-red)
- Fake green: files written without covering use cases
